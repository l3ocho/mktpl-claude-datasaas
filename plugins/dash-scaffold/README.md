# dash-scaffold v1.0.0

Dash application scaffolding plugin for Claude Code.

## Scope

Dash layouts, pages, AppShell, navbar, and responsive breakpoints.

## Commands

| Command | Description |
|---------|-------------|
| `/dash dashboard [template]` | Create a Dash dashboard layout |
| `/dash page <n>` | Create a new Dash page |
| `/dash breakpoints` | Configure responsive breakpoints |

## Agents

| Agent | Description |
|-------|-------------|
| `layout-builder` | Practical dashboard layout specialist |

## Skills

`layout-templates.md`, `responsive-design.md`

## MCP

None — skill-driven only.

## Migration from viz-platform

`/viz dashboard` → `/dash dashboard`, `/viz breakpoints` → `/dash breakpoints`.
See `docs/MIGRATION-v11.md`.
